## Scope

### In scope (login flow, deep)

- Sign-in page load and form visibility
- Happy-path login with `standard_user` (DATA-001) and named password (DATA-002)
- Invalid credential rejection (wrong password, unknown username)
- Account-state negatives that block inventory (locked account per REQ-003)
- Required-field validation (empty username, empty password, both empty)
